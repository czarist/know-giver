Know Giver — AIと音声レッスンで、あらゆる試験の勉強を（公務員試験、入試、資格）

はじめかた
1. Know Giver を開きます。
2. 初回設定で、言語と国・地域、名前、先生、AIサービスとキー、規約への同意を
   選びます。その後、画面を案内する短いツアーがあります。
3. 設定で音声モデル（音声認識と先生の声）をダウンロードします。お使いの
   コンピューターで動きます。日本語のレッスンは、現在は文字でのやり取りです。
4. 試験要項で要項のPDFを選び、学習プランを作ります。

アップデート
新しいバージョンが出ると、アプリの上部に緑のボタン付きのバーが表示されます。
設定 > アプリについて・アップデート で確認をオフにできます。

データ
%LOCALAPPDATA%\KnowGiver に保存されます（データベースとダウンロードしたモデル）。
AIのキーはアプリの設定に保存されます。.env ファイルは共有しないでください。

アンインストール
Windows の 設定 > アプリ > Know Giver、スタートメニューの「Uninstall Know Giver」、
またはこのフォルダーの unins000.exe。このフォルダーを削除し、学習データも削除するか
確認します。「いいえ」の場合は残ります。

コード、ヘルプ、新機能：https://github.com/czarist/know-giver
