Know Giver — 用 AI 與語音課堂準備任何考試（國家考試、升學考試、證照）

開始使用
1. 開啟 Know Giver。
2. 首次設定會詢問語言與地區、你的名字、老師、AI 服務與金鑰，以及是否同意條款。
   之後會有簡短的介面導覽。
3. 在「設定」中下載語音模型（語音辨識與老師的聲音），它們在你的電腦上執行。
   中文課堂目前以文字進行。
4. 在「考試公告」中選擇簡章 PDF，產生學習計畫。

更新
有新版本時，程式頂端會出現一條附綠色按鈕的提示列。
可在 設定 > 關於與更新 中關閉檢查。

你的資料
儲存在 %LOCALAPPDATA%\KnowGiver（資料庫與下載的模型）。
AI 金鑰儲存在程式設定中；請勿分享 .env 檔案。

解除安裝
Windows 設定 > 應用程式 > Know Giver、開始功能表中的「Uninstall Know Giver」，或本資料夾中的
unins000.exe。解除安裝程式會刪除本資料夾，並詢問是否一併刪除學習資料；選擇「否」則保留。

程式碼、說明與更新內容：https://github.com/czarist/know-giver
