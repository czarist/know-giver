# Know Giver 隐私政策

2026年11月3日版本（2026-11-03.4）。本版本适用于在新加坡使用本应用的用户，依据新加坡《个人数据保护法》（Personal Data Protection Act 2012，PDPA）编写。本中文版为译本，如与英文版有任何不一致，以英文版为准。

## 1. 摘要

- Know Giver 在你的电脑上运行。Trentin 没有为本应用设置服务器，**不会接收、存储或访问你的数据**。
- 没有 Trentin 账户、遥测、使用分析、广告，也不会出售或分享个人数据。
- 每项任务所需的内容会使用该服务商要求的认证方式（API 密钥或官方账户登录）发送给**你选择的 AI 服务商**，由该服务商按其条款处理。

## 2. 负责单位

本应用由 TRENTIN SOLUCOES EM SOFTWARE LTDA – ME（巴西，CNPJ 36.154.590/0001-54，联系方式：https://trentin.software）开发。由于 Trentin 不通过本应用收集、使用或披露个人数据，因此不是你在应用中所用数据的机构（organisation）或数据中介。你发送给 AI 服务商或其他你开启的服务的数据，由各该服务按你与其之间的约定负责处理。

## 3. 保存在你电脑上的数据

应用的数据文件夹（Windows 为 `%LOCALAPPDATA%\KnowGiver`，或 `KG_DATA_DIR` 指定的文件夹）中保存：

- 你的名字（老师对你的称呼）、语言、国家或地区、老师和其他偏好设置；
- API 密钥（在应用中输入时，以未加密方式保存在本地数据库）；
- 使用 GitHub Copilot 时，登录凭据由官方 Copilot CLI 管理。CLI 通常使用操作系统密钥链；如果密钥链不可用，可能会改为将凭据保存在明文配置文件（`~/.copilot/config.json`）中。Know Giver 不会将其保存在应用数据库中；
- 使用 ChatGPT 时，“Sign in with ChatGPT”的令牌（访问令牌和刷新令牌）、账号的电子邮件地址、应用在 OpenAI 的注册信息，以及这台电脑的随机标识符（每次登录时发送给 OpenAI，用于区分你的电脑，不能识别你本人），会像 API 密钥一样以未加密方式保存在本地数据库；退出登录时会请求 OpenAI 撤销刷新令牌；
- 使用 Claude 时，Anthropic 官方的 Claude Code 在其文件夹（`~/.claude`）或操作系统密钥链中管理你的 Claude 账号登录。Know Giver 不会查看或保存这些凭据；
- 你上传的考试公告、历年真题、答案和资料，以及计划、进度、测验、复习、讲义、标记和笔记；
- 课堂对话和错题本；
- 主观题作答的照片、转写和评分；
- 安装本地 OCR 时下载并保存在本地模型文件夹中的 PaddleOCR-VL 模型文件；
- 你同意本文件的日期和时间；
- 技术日志（不记录图片、作答或密钥）。

麦克风的声音在你的电脑上转成文字，不会发送到任何地方。

## 4. 哪些数据会离开你的电脑，发给谁

| 接收方 | 发送的内容 | 何时 |
|---|---|---|
| 你选择的 AI 服务商 | 考试公告和资料的摘录、知识点、你的消息和转写的作答、你的名字（让老师称呼你）、讲义文字 | 每项 AI 任务 |
| 通过 llama.cpp v0.8.0 `llama-server` 在本地运行的 PaddleOCR-VL | 主观题作答的照片 | 默认使用；在你的电脑上处理，不发送给服务商 |
| 服务商的图片模型 | 主观题作答的照片和扫描版 PDF 的页面 | 仅在你明确选择外部 OCR 时发送作答照片；扫描 PDF 页面仅在你配置图片模型并请求识别时发送 |
| Wikipedia | 板书图片的搜索词 | 开启板书图片时 |
| Hugging Face、GitHub 和语音网站 | 下载请求（会显示你的 IP 地址） | 下载语音、语音识别或 OCR 模型时 |
| GitHub | 查询最新版本的请求（会显示你的 IP 地址和应用版本）；你选择更新时，新版本的安装包 | 开启“打开时检查更新”时，每次打开应用（设置 → 关于与更新） |
| 云端语音服务 | 老师要说的文字 | 仅在你开启云端语音时 |

Windows/Linux 软件包包含带 Vulkan 支持的 llama.cpp 运行时。检测到兼容 GPU 时，应用使用电脑上已安装的 Vulkan 驱动；找不到设备或 GPU 启动失败时，OCR 回退到 CPU。macOS 使用 CPU。运行时和 GPU 驱动在本地处理 OCR；Vulkan 后端不是数据接收方，不会将照片发送给 Trentin 或服务商。

选择 GitHub Copilot 时，AI 服务商一行所述内容会发送给 GitHub。登录通过 Copilot CLI 完成。CLI 通常将凭据保存在操作系统密钥链中；如果密钥链不可用，可能会改为保存到明文配置文件（`~/.copilot/config.json`）。Know Giver 不会将这些凭据保存在应用数据库中。

选择 ChatGPT 时，同样的内容通过 Responses API 发送给 OpenAI，并计入你 ChatGPT 套餐的用量上限；Know Giver 以自己的名称在 OpenAI 注册，不会获得你在 ChatGPT 中的对话。选择 Claude 时，内容通过安装在你电脑上的 Claude Code 发送给 Anthropic；Know Giver 运行 Claude Code 时不使用工具、MCP 服务器或你的设置，用量计入你 Claude 订阅的上限。如果你让 Know Giver 安装 Claude Code，官方安装程序会从 claude.ai 下载，这会暴露你的 IP 地址。

许多 AI 服务商位于其他国家或地区，选择服务商可能使数据传输到境外。保护措施由服务商提供。选择前请先阅读其隐私政策。

## 5. 目的

数据只用于让应用运行：制定计划、上课、出题和编写讲义、评分以及显示进度。

## 6. 安全

数据保存在你的电脑上，受你的用户账户访问权限保护；请为电脑设置密码。在应用中输入的 API 密钥以未加密方式保存在本地数据库；GitHub Copilot 登录凭据由 CLI 管理，通常保存在操作系统密钥链中；密钥链不可用时，CLI 可能改用明文配置文件。Know Giver 不会将凭据保存在应用数据库中。ChatGPT 令牌像 API 密钥一样以未加密方式保存在本地数据库；Claude 的凭据由 Claude Code 管理。安全问题可按项目的 SECURITY.md 报告。

## 7. 保存期限

数据保存在你的电脑上，直到你删除为止。删除主观题的作答会一并删除其照片；删除数据文件夹会移除全部数据。发送给服务商的数据按各服务商的保存规则处理。

## 8. 你的权利

你可以在应用中直接查看、更正、导出和删除自己的数据。Trentin 没有保存你的个人数据，因此没有可向 Trentin 请求访问或更正的数据。对于发送给服务商的数据，请向该服务商行使权利。你也可以就数据处理联系个人数据保护委员会（PDPC）。

## 9. 未成年人

未成年人应在父母或监护人知情并同意的情况下使用本应用。

## 10. 人工智能

AI 生成的回答可能存在错误，质量取决于你所选模型的能力限制。请参阅使用条款第 6 条。

## 11. 变更

本政策变更时，新版本会有新的日期，应用会再次请你同意。
