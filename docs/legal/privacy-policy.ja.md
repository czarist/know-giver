# Know Giver プライバシーポリシー

2026年10月31日版（2026-10-31）。個人情報の保護に関する法律（個人情報保護法）および電気通信事業法の外部送信規律に基づく、日本でアプリを利用するお客様向けの版です。

## 1. 概要

- Know Giver はお客様のコンピューター上で動作します。当社はアプリのためのサーバーを持たず、**お客様のデータを受け取ること、保存すること、閲覧することはありません**。
- 当社のアカウント登録、テレメトリー、利用状況の分析、広告、データの販売はありません。
- 各作業に必要な内容は、お客様のキーで、**お客様が選んだAI提供元**に送られます。その提供元が、自身の規約に基づいて取り扱います。

## 3. お客様のコンピューターに保存される情報

アプリのデータフォルダ（Windows では `%LOCALAPPDATA%\KnowGiver`、または `KG_DATA_DIR` で指定したフォルダ）には次の情報が保存されます。

- 名前（先生が呼ぶ名前）、言語、国・地域、先生などの設定
- APIキー（アプリで入力した場合、ローカルのデータベースに暗号化されずに保存）
- アップロードした試験要項、過去問、解答、資料、およびプラン、進捗、クイズ、復習、テキスト、マーカー、メモ
- レッスンの会話と間違いノート
- 記述答案の写真、その書き起こしと採点
- 本書に同意した日時
- 技術的なログ（画像、答え、キーは記録しません）

マイクの音声はお客様のコンピューター上で文字にされ、どこにも送られません。

## 4. 外部送信（お客様のコンピューターから送られる情報と送信先）

| 送信先 | 送信される情報 | 送信される場面と目的 |
|---|---|---|
| お客様が選んだAI提供元 | 試験要項・資料の抜粋、トピック、お客様のメッセージと書き起こした答え、お客様の名前（先生が呼びかけるため）、テキストの文章 | AIの各作業のたび（プラン、レッスン、クイズ、採点などのため） |
| 提供元の画像対応モデル | 記述答案の写真、スキャンしたPDFのページ | 画像対応モデルを設定し、写真を送った場合のみ（書き起こしのため） |
| Wikipedia | 板書の画像の検索語 | 板書の画像がオンの場合（画像を表示するため） |
| Hugging Face、GitHub、音声の配布サイト | ダウンロードの要求（IPアドレスが分かります） | 音声・音声認識モデルをダウンロードする場合 |
| GitHub | 最新バージョンの問い合わせ（IPアドレスとアプリのバージョンが分かります）、アップデートを選んだ場合は新しいバージョンのパッケージ | アップデートの確認がオンの場合、アプリを開くたび（設定 → アプリについて・アップデート） |
| クラウド音声サービス | 先生が話す文章 | クラウド音声をオンにした場合のみ（読み上げのため） |

多くのAI提供元は外国にあります。提供元を選ぶと、情報が外国に送られることがあります。保護の措置は提供元が提供するものです。選ぶ前に、提供元のプライバシーポリシーをご確認ください。

## 5. 利用目的

情報は、アプリを動かすため（プランの作成、レッスン、問題とテキストの作成、採点、進捗の表示）にだけ使われます。

## 6. 安全管理

情報はお客様のコンピューターに保存され、お使いのユーザーアカウントへのアクセスによって保護されます。コンピューターにはパスワードを設定してください。APIキーはローカルのデータベースに暗号化されずに保存されます。セキュリティ上の問題は、プロジェクトの SECURITY.md に従ってご報告ください。

## 7. 保存期間

情報は、お客様が削除するまでお客様のコンピューターに残ります。記述答案の取り組みを削除するとその写真も削除され、データフォルダを削除するとすべてが消えます。提供元に送られた情報は、各提供元の保存期間に従います。

## 8. 開示等の請求

アプリの中で、ご自身の情報を確認、訂正、書き出し、削除できます。当社はお客様の個人情報を保有していないため、当社に対する開示等の請求の対象となる情報はありません。AI提供元に送った情報については、その提供元にご請求ください。

## 9. 未成年の方

未成年の方は、親権者など法定代理人の同意を得て、その関与のもとでアプリを利用してください。

## 10. 人工知能について

AIが生成する回答は誤りを含むことがあり、その品質はお客様が選んだモデルの限界に左右されます。利用規約第6条をご覧ください。

本ポリシーを変更した場合、新しい版には新しい日付が付き、アプリは改めて同意を求めます。
