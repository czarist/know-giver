# Know Giver 개인정보 처리방침

2026년 11월 25일 버전(2026-11-25.1). 「개인정보 보호법」(PIPA)에 따라 작성한, 대한민국에서 앱을 이용하는 분을 위한 버전입니다.

## 1. 요약

- Know Giver는 사용자의 컴퓨터에서 실행됩니다. 회사는 앱을 위한 서버가 없으며, **사용자의 데이터를 수집, 저장, 열람하지 않습니다**.
- 회사 계정, 원격 측정(텔레메트리), 이용 분석, 광고, 개인정보의 판매나 공유가 없습니다.
- 각 작업에 필요한 내용은 **사용자가 선택한 AI 제공자**에게, 그 제공자가 요구하는 인증 방법(API 키 또는 공식 계정 로그인)으로 전송됩니다. 제공자는 자체 약관에 따라 이를 처리합니다.

## 2. 사업자와 책임

앱은 TRENTIN SOLUCOES EM SOFTWARE LTDA – ME(브라질, CNPJ 36.154.590/0001-54, 이하 "회사", 문의: https://trentin.software)가 개발합니다. 회사는 앱을 통해 개인정보를 수집하거나 처리하지 않으므로, 앱에서 사용하는 정보에 대해 개인정보처리자나 수탁자가 아닙니다. 사용자가 AI 제공자나 사용자가 켠 그 밖의 서비스에 보내는 정보는 사용자와 해당 서비스 사이의 계약에 따라 각 서비스가 책임지고 처리합니다.

## 3. 사용자의 컴퓨터에 저장되는 항목

앱의 데이터 폴더(Windows에서는 `%LOCALAPPDATA%\KnowGiver`, 또는 `KG_DATA_DIR`로 지정한 폴더)에는 다음 항목이 저장됩니다.

- 이름(선생님이 부르는 이름), 언어, 국가·지역, 선생님 등 설정
- API 키(앱에서 입력한 경우, 로컬 데이터베이스에 암호화되지 않은 상태로 저장)
- GitHub Copilot의 경우 공식 Copilot CLI가 로그인 정보를 관리합니다. 보통 운영체제의 키체인을 사용하며, 사용할 수 없으면 일반 텍스트 설정 파일(`~/.copilot/config.json`)에 저장할 수 있습니다. Know Giver는 이를 데이터베이스에 저장하지 않습니다.
- ChatGPT의 경우 "Sign in with ChatGPT" 토큰(액세스 토큰과 갱신 토큰), 계정 이메일, OpenAI에 대한 앱 등록 정보, 이 컴퓨터의 무작위 식별자(로그인할 때마다 사용자의 컴퓨터를 구별하기 위해 OpenAI에 전송되며, 사용자 개인을 식별하지 않습니다)를 API 키와 마찬가지로 로컬 데이터베이스에 암호화하지 않고 저장합니다. 로그아웃하면 OpenAI에 갱신 토큰의 취소를 요청합니다.
- Claude의 경우 Anthropic의 공식 Claude Code가 자체 폴더(`~/.claude`) 또는 운영체제의 키체인에서 Claude 계정 로그인을 관리합니다. Know Giver는 그 인증 정보를 보거나 저장하지 않습니다.
- 업로드한 시험 공고문, 기출문제, 정답, 자료와 학습 계획, 진도, 퀴즈, 복습, 학습 자료, 형광펜 표시, 메모
- 수업 대화와 오답 노트
- 서술형 답안의 사진, 그 판독 결과와 채점
- 로컬 OCR을 설치한 경우 로컬 모델 폴더에 내려받은 PaddleOCR-VL 모델 파일
- 본 문서에 동의한 날짜와 시각
- 기술 로그(이미지, 답안, 키는 기록하지 않습니다)

마이크 음성은 사용자의 컴퓨터에서 텍스트로 변환되며 어디에도 전송되지 않습니다. 임시 진단용 녹음은 데이터 폴더에 남습니다. 앱은 쿠키 등 자동으로 개인정보를 수집하는 장치를 설치하거나 운영하지 않습니다.

## 4. 처리 목적

정보는 앱을 작동시키기 위해서만, 즉 학습 계획 작성, 수업 진행, 문제와 학습 자료 작성, 답안 채점, 진도 표시를 위해서만 사용됩니다.

## 5. 컴퓨터 밖으로 전송되는 정보와 수신자(제3자 제공 및 국외 이전)

| 수신자 | 전송되는 항목 | 전송 시점과 목적 |
|---|---|---|
| 사용자가 선택한 AI 제공자 | 시험 공고문과 자료의 발췌, 주제, 사용자의 메시지와 변환된 답변, 사용자의 이름(선생님이 부르기 위해), 학습 자료의 텍스트 | AI 작업마다(학습 계획, 수업, 퀴즈, 채점 등을 위해) |
| llama.cpp v0.8.0 `llama-server`로 로컬에서 실행되는 PaddleOCR-VL | 서술형 답안의 사진 | 기본값. 사용자의 컴퓨터에서 처리되며 제공자에게 전송되지 않습니다 |
| 제공자의 이미지 인식 모델 | 서술형 답안의 사진, 스캔한 PDF의 페이지 | 답안 사진은 외부 OCR을 명시적으로 선택한 경우에만, 스캔 PDF는 이미지 인식 모델을 설정하고 OCR을 요청한 경우에만 |
| Wikipedia | 칠판 그림의 검색어 | 칠판 그림을 켠 경우(그림을 보여 주기 위해) |
| Hugging Face, GitHub, 음성 배포 사이트 | 다운로드 요청(IP 주소가 상대방에게 표시됩니다) | 음성, 음성 인식, OCR 모델을 내려받을 때 |
| GitHub | 최신 버전 확인 요청(IP 주소와 앱 버전이 표시됩니다), 업데이트를 선택한 경우 새 버전의 패키지 | 업데이트 확인을 켠 경우 앱을 열 때마다(설정 → 앱 정보 및 업데이트) |
| 클라우드 음성 서비스 | 선생님이 말할 텍스트 | 클라우드 음성을 켠 경우에만(읽어 주기 위해) |

Windows와 Linux 패키지에는 Vulkan을 지원하는 llama.cpp 런타임이 포함되어 있습니다. 호환되는 GPU가 있으면 컴퓨터에 설치된 Vulkan 드라이버를 사용하며, 장치를 찾지 못하거나 GPU 시작에 실패하면 OCR은 CPU로 전환됩니다. macOS는 CPU를 사용합니다. 런타임과 GPU 드라이버는 OCR을 로컬에서 처리합니다. Vulkan 백엔드는 수신자가 아니며 사진을 Trentin이나 제공자에게 보내지 않습니다.

GitHub Copilot을 선택하면 AI 제공자 행에 적힌 내용이 GitHub로 전송됩니다. 로그인은 Copilot CLI를 통해 이루어지며, 보통 운영체제의 키체인에 인증 정보를 저장하고, 키체인을 사용할 수 없으면 일반 텍스트 설정 파일(`~/.copilot/config.json`)에 저장할 수 있습니다. Know Giver는 이를 데이터베이스에 저장하지 않습니다.

ChatGPT를 선택하면 같은 내용이 Responses API를 통해 OpenAI로 전송되며 ChatGPT 요금제의 한도에 포함됩니다. Know Giver는 자체 이름으로 OpenAI에 등록되어 있으며 ChatGPT 대화를 받지 않습니다. Claude를 선택하면 내용은 사용자의 컴퓨터에 설치된 Claude Code를 통해 Anthropic으로 전송됩니다. Know Giver는 도구, MCP 서버, 사용자의 설정 없이 Claude Code를 실행하며, 이용량은 Claude 구독의 한도에 포함됩니다. Know Giver에 Claude Code 설치를 요청하면 공식 설치 프로그램을 claude.ai에서 내려받으며, 이때 IP 주소가 상대방에게 표시됩니다.

### 국외 이전에 관한 사항

많은 AI 제공자가 국외에 있으므로, 제공자를 선택하면 개인정보가 국외로 이전될 수 있습니다. 이 이전은 사용자가 직접 선택한 제공자에게, 사용자의 컴퓨터에서 직접 이루어지며 회사를 거치지 않습니다.

- **이전되는 항목**: 위 표의 AI 제공자 행과 이미지 인식 모델 행에 적힌 항목
- **이전되는 국가**: 사용자가 선택한 제공자가 정보를 처리하는 국가(제공자의 개인정보 처리방침에서 확인할 수 있습니다)
- **이전 시점과 방법**: AI 작업을 요청할 때마다 인터넷을 통해 암호화된 연결(HTTPS)로 전송
- **이전받는 자**: 사용자가 설정에서 선택한 제공자(예: Z.ai, Anthropic, OpenAI, Google, GitHub). 연락처는 각 제공자의 개인정보 처리방침에 있습니다
- **이전받는 자의 이용 목적과 보유 기간**: 요청한 AI 응답의 생성. 보유 기간은 각 제공자의 정책을 따릅니다
- **거부 방법과 거부 시 효과**: 국외 제공자를 선택하지 않거나 로컬 서버를 사용하면 이전을 거부할 수 있습니다. 이 경우 국외 제공자를 사용하는 AI 기능은 작동하지 않습니다

보호 조치는 제공자가 사용자에게 제공하는 것입니다. 제공자를 선택하기 전에 그 개인정보 처리방침을 읽어 보십시오.

## 6. 안전성 확보 조치

정보는 사용자의 컴퓨터에 저장되며, 사용자 계정에 대한 접근 통제로 보호됩니다. 컴퓨터에 비밀번호를 설정하십시오. 앱에서 입력한 API 키는 로컬 데이터베이스에 암호화되지 않은 상태로 저장됩니다. GitHub Copilot 로그인 정보는 CLI가 관리하며 보통 운영체제의 키체인에 저장되고, 키체인을 사용할 수 없으면 일반 텍스트 설정 파일에 저장될 수 있습니다. Know Giver 데이터베이스에는 저장되지 않습니다. ChatGPT 토큰은 API 키와 마찬가지로 로컬 데이터베이스에 암호화되지 않은 상태로 저장되며, Claude 인증 정보는 Claude Code가 관리합니다. 보안 문제는 프로젝트의 SECURITY.md에 따라 신고해 주십시오.

## 7. 보유 기간과 파기

정보는 사용자가 삭제할 때까지 사용자의 컴퓨터에 남습니다. 서술형 답안 시도를 삭제하면 그 사진도 삭제되며, 데이터 폴더를 삭제하면 모든 정보가 파기됩니다. 제공자에게 전송된 정보는 각 제공자의 보유 기간을 따릅니다.

## 8. 정보주체의 권리와 행사 방법

앱 안에서 자신의 정보를 직접 열람, 정정, 내보내기, 삭제할 수 있습니다. 회사는 사용자의 개인정보를 보유하지 않으므로, 회사에 대한 열람, 정정·삭제, 처리정지 요구의 대상이 되는 정보가 없습니다. AI 제공자에게 보낸 정보에 대해서는 해당 제공자에게 권리를 행사하십시오.

## 9. 아동과 미성년자

만 14세 미만 아동은 법정대리인의 동의를 받아 그 관여 아래에서만 앱을 이용하십시오. 회사는 아동의 개인정보를 알면서 수집하지 않습니다. 법정대리인은 AI 제공자의 선택과 사용하는 키에 대해서도 책임을 집니다.

## 10. 인공지능

AI가 생성한 답변에는 오류가 있을 수 있으며, 그 품질은 사용자가 선택한 모델의 한계에 따라 달라집니다. 이용약관 제6조를 참고하십시오.

## 11. 변경

본 방침이 변경되면 새 버전에는 새 날짜가 붙으며, 앱은 다시 동의를 요청합니다.
