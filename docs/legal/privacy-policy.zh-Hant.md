# Know Giver 隱私權政策

2026年10月31日版本（2026-10-31）。本版本適用於在臺灣（個人資料保護法）及香港（《個人資料（私隱）條例》）使用本程式的使用者。

## 1. 摘要

- Know Giver 在你的電腦上執行。Trentin 沒有為本程式設置伺服器，**不會接收、儲存或存取你的資料**。
- 沒有 Trentin 帳號、遙測、使用分析、廣告，也不會出售或分享個人資料。
- 每項工作所需的內容，會使用你的金鑰傳送給**你選擇的 AI 服務商**，由該服務商依其條款處理。

## 2. 負責單位

本程式由 TRENTIN SOLUCOES EM SOFTWARE LTDA – ME（巴西，CNPJ 36.154.590/0001-54，聯絡方式：https://trentin.software）開發。由於 Trentin 不透過本程式蒐集、處理或利用個人資料，因此並非你在程式中所使用資料的蒐集者或資料使用者。你傳送給 AI 服務商或其他你開啟的服務的資料，由各該服務依你與其之間的約定負責處理。

## 3. 儲存在你電腦上的資料

程式的資料資料夾（Windows 為 `%LOCALAPPDATA%\KnowGiver`，或 `KG_DATA_DIR` 指定的資料夾）中儲存：

- 你的名字（老師對你的稱呼）、語言、國家或地區、老師及其他偏好設定；
- API 金鑰（在程式中輸入時，以未加密方式儲存在本機資料庫）；
- 你上傳的考試簡章、考古題、答案及資料，以及計畫、進度、測驗、複習、講義、標記和筆記；
- 課堂對話及錯題本；
- 申論題作答的照片、轉寫及評分；
- 你同意本文件的日期與時間；
- 技術日誌（不記錄圖片、作答或金鑰）。

麥克風的聲音會在你的電腦上轉成文字，不會傳送到任何地方。

## 4. 哪些資料會離開你的電腦，傳給誰

| 接收者 | 傳送的內容 | 何時 |
|---|---|---|
| 你選擇的 AI 服務商 | 考試簡章和資料的摘錄、知識點、你的訊息和轉寫的作答、你的名字（讓老師稱呼你）、講義文字 | 每項 AI 工作 |
| 服務商的圖片模型 | 申論題作答的照片及掃描 PDF 的頁面 | 僅在你設定圖片模型並傳送照片時 |
| Wikipedia | 板書圖片的搜尋詞 | 開啟板書圖片時 |
| Hugging Face、GitHub 及語音網站 | 下載請求（會顯示你的 IP 位址） | 下載語音或語音辨識模型時 |
| GitHub | 查詢最新版本的請求（會顯示你的 IP 位址與程式版本）；你選擇更新時，新版本的安裝包 | 開啟「開啟時檢查更新」時，每次開啟程式（設定 → 關於與更新） |
| 雲端語音服務 | 老師要說的文字 | 僅在你開啟雲端語音時 |

許多 AI 服務商位於其他國家或地區，選擇服務商可能使資料傳送到境外。保護措施由服務商提供。選擇前請先閱讀其隱私權政策。

## 5. 目的

資料只用於讓程式運作：製作計畫、上課、出題與編寫講義、評分以及顯示進度。

## 6. 安全

資料儲存在你的電腦上，受你的使用者帳號存取權限保護；請為電腦設定密碼。API 金鑰以未加密方式儲存在本機資料庫。安全問題可依專案的 SECURITY.md 回報。

## 7. 保存期間

資料保存在你的電腦上，直到你刪除為止。刪除申論題的作答會一併刪除其照片；刪除資料資料夾會移除全部資料。傳送給服務商的資料依各服務商的保存規則處理。

## 8. 你的權利

你可以在程式中直接查詢、更正、匯出及刪除自己的資料。Trentin 並未保有你的個人資料，因此沒有可向 Trentin 請求查詢、閱覽、複製、補充、更正、停止蒐集處理利用或刪除的資料。對於傳送給服務商的資料，請向該服務商行使權利。

### 臺灣

你依個人資料保護法第 3 條享有的權利，請向實際蒐集你資料的服務商行使。

### 香港

你可就資料的處理聯絡個人資料私隱專員公署。

## 9. 未成年人

未成年人應在法定代理人知悉並同意下使用本程式。

## 10. 人工智慧

AI 產生的回答可能有錯誤，品質取決於你所選模型的能力限制。請參閱使用條款第 6 條。
