# Know Giver パートナーアクセス規約

2026年10月31日版（2026-10-31）。本規約は、Know Giver を一般に提供していないすべての国・地域に適用されます。

## 1. 一般には提供していません

TRENTIN SOLUCOES EM SOFTWARE LTDA – ME（ブラジル、CNPJ 36.154.590/0001-54。以下「Trentin」）が開発する Know Giver は、ブラジル、アメリカ合衆国、欧州連合、イギリス、日本、台湾、香港、シンガポールでのみ一般に提供しています。その他のすべての国・地域では、**一般に提供、販売、公開していません**。

## 2. 認定パートナーのみ

これらの地域では、Trentin が**書面の契約**で認めた組織と個人だけが、試験と評価のためにアプリを利用できます。認定はパートナーと指定された担当者に限られ、譲渡や再許諾はできません。Trentin はいつでも認定を取り消すことができ、認定は書面の契約の終了とともに終わります。認定パートナーでない方は、これらの地域でアプリを利用しないでください。

## 3. パートナーの義務

- アプリを利用する場所で適用されるすべての法令（個人情報、サイバーセキュリティ、オンラインコンテンツ、人工知能、輸出管理に関する規則を含む）を守ること。
- 所在地で適法に利用できるAI提供元だけを使い、各提供元の規約と提供地域に従うこと。アプリは提供元を一覧にしていますが、特定の場所での利用を適法にするものではありません。
- 法的根拠なく他人の個人情報を入力しないこと。
- アプリ、その結果、アプリへのアクセスを一般に配布せず、公衆向けのサービスとして示さないこと。
- 書面の契約に従い、アプリ、その結果、試験の条件を秘密として扱うこと。
- 合意したとおり、問題や意見を Trentin に報告すること。

## 4. 人工知能について

回答、プラン、テキスト、問題、書き起こし、採点は人工知能が生成するもので、**誤りを含むことがあります**。品質は、**選んだAIの限界**（モデルの能力、扱える文脈の長さ、言語の性能、画像の読み取り、利用上限、稼働状況）に左右されます。結果に頼る前に、公式の情報を確認してください。

## 5. データ

アプリはパートナーのコンピューター上で動作します。Trentin はアプリのためのサーバーを持たず、アプリで使われるデータを受け取ること、保存すること、閲覧することはありません。各作業に必要な内容は、パートナーのキーで、パートナーが選んだAI提供元に送られ、提供元が自身の規約に基づいて（外国で取り扱う場合も含め）取り扱います。そのデータとその移転については、パートナーが責任を負います。

## 6. 無保証と責任の制限

アプリは試験のために、無償で、現状有姿で提供され、いかなる保証もありません。法令で認められる最大限の範囲で、Trentin は間接損害、AI提供元の料金、AIの回答に基づく判断、データの消失について責任を負いません。法令上免除できない責任は残ります。
